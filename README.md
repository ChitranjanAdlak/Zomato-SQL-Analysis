# 🍽️ Zomato SQL Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing a simulated Zomato food delivery database using SQL. The database contains information about customers, restaurants, employees, food items, orders, and payments.

The objective of this project is to extract meaningful business insights using SQL queries to understand customer behaviour, restaurant performance, food popularity, revenue, and delivery efficiency.

## 🎯 Project Objectives
- Analyze customer ordering behaviour.
- Identify top-performing restaurants.
- Analyze food item popularity and revenue.
- Evaluate delivery time and employee ratings.
- Explore payment patterns.
- Extract meaningful insights using SQL.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## 🗂️ Database Structure

The database consists of the following tables:

| Table Name | Description |
|---|---|
| `customer` | Stores customer information |
| `restaurant` | Contains restaurant details and ratings |
| `zomato_employee` | Stores delivery employee information and ratings |
| `foods` | Contains food items and prices |
| `order_detail` | Stores order details and timestamps |
| `payment_table` | Contains payment type and payment status |
| `order_food` | Connects orders with food items and quantities |

## 📊 Business Questions & Analysis

This project explores the following business questions:

1. Identify the top 3 customers who placed the highest number of orders.
2. Find the restaurant with the highest average rating.
3. Identify orders delivered in less than 30 minutes.
4. Calculate total revenue generated by each food item.
5. Find the second-highest revenue-generating restaurant.
6. Identify the 5 most popular food items based on quantity sold.
7. Find the top 3 employees with the highest average ratings.
8. Determine the month with the highest number of orders.
9. Calculate the average order amount for each customer.
10. Identify customers who order most frequently from each restaurant.
11. Calculate the total number of orders placed on weekends.
12. Compare average delivery time on weekdays and weekends.
13. Identify the 5 most expensive food items.
14. Find the restaurant with the most diverse menu based on ordered food items.
15. Calculate the total payment amount for each payment type.
